What the big screen shows

Prize giving

These winners appear on the big screen when Prize giving is selected above. Auto-fill uses each sport's final (a round named "Final", and "3rd place" if played) or, without a final, the group table – and the bowling standings. Check the names before showing.

Public live-score page (for the QR code)

Print the QR on banners and the big screen. Spectators can choose any sport on the page.

Scorer links (send each AJK only their sport's link + password)

Scorer QR codes

Each committee scans their own sport's code to open the scorer page. Give the password separately – never print it on this sheet.

Tenpin bowling (separate page)

Bowling has its own scorer, public page and OBS panel. Its public page is also linked from the main live-scores page.

Big screen links for OBS (Browser Source, 1920 × 1080)

Download results

One file with every match, score and group table for all sports, plus bowling standings. Opens in Excel.

Refresh public data

Rebuilds what the big screen and public page show from the scorers' data. Use it if something looks out of date.

Activity log

Clear a sport (after testing)

Deletes every match and team of one sport. Cannot be undone.
