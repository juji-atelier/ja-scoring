Live score page · which sports show

Untick Show to take a sport off the public live-score page (its tile disappears; anyone on it is moved to another sport). Tick Completed when a sport has finished: its final results are kept and shown from then on, even if the scorer page or the ML console is cleared. Changes reach phones within about a minute.

Mobile Legends · kept results

While this Admin page is open, the latest results from the JA ESPORT console are copied automatically. If you clear the ML console, the public page and big screen keep showing that copy. Tick Completed above to lock it so a new game in the console does not replace it.

Reset live score system

Deletes every kept copy and un-ticks every Completed, so the live-score page goes back to showing the scorers' and the ML console's current data. Show / hide choices stay. Scorer data, bowling and the ML console are not touched.

What the big screen shows

Sport names, dates & venues

Shown at the top of each scorer page, on the public page's sport tabs and on the big screen. Leave a box empty to keep the standard text shown in grey. An empty venue means the main venue above.

Prize giving

These winners appear on the big screen when Prize giving is selected above. Auto-fill uses each sport's final (a round named "Final", and "3rd place" if played) or, without a final, the group table – and the bowling standings. Check the names before showing.

Public live-score page (for the QR code)

Download results

One file with every match, score and group table for all sports, plus bowling standings. Opens in Excel.

Backup & restore

A backup is one file with everything: all sports' teams, matches and scores, bowling, Mobile Legends and your settings. Download one before each day starts and after each sport finishes. If something is deleted by mistake, choose the file below to put it back.

Refresh public data

Rebuilds what the big screen and public page show from the scorers' data. Use it if something looks out of date.
